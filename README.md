# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |
| svg | demo.txt, demo_32.pgm, demo_256.pgm | SVG 路径解析、三次贝塞尔细分与 PGM 填充 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## svg 模块：三次贝塞尔段

`svg_parse_ex()` 通过 `VParseOpt.enable_cubic` 选择性支持 `C`/`c`。未启用时
行为与旧的 `svg_parse()` 完全一致：`C` 仍然返回 `-3`，分段与填充逐字节相同。

启用后，每个 `C` 坐标组（控制点 1、控制点 2、端点）按容差自适应细分：两个控制点
到弦的距离都不超过 `tol` 时停止，结果作为 `SV_LINE` 段追加进 `VPath`。`tol`
以路径的用户单位计，必须有限且大于 0，否则返回 `SVG_ERR_TOL`。每个 `C`/`c`
只接受恰好一组（3 对）坐标；坐标对数不对（少、多或后面多出数字）都按控制点数
错误处理。

错误码：

| 码 | 含义 |
|---|---|
| -1..-5 | 与旧解析器相同（参数、起始命令、未知命令、坐标缺失、段数上限） |
| -6 `SVG_ERR_CTRL_COUNT` | `C`/`c` 的坐标不是恰好 3 对 |
| -7 `SVG_ERR_NOT_FINITE` | 坐标为 NaN 或无穷 |
| -8 `SVG_ERR_TOL` | 启用细分但容差非有限或非正 |

`err_seg` 给出出错的段号（从 1 开始）：`L`、每个 `C` 字母、`Z` 各占一个段号；
`M`/`m` 是移动不是绘图段，不占段号，`M` 内出错时报告下一个绘图段的段号。
`svg_strerror()` 返回对应文字。

测试用一段两段三次贝塞尔的 64 点手写折线做参考，按像素比对填充结果，偏差上界
一个像素；同时用改动前的仓内解析器算出的哈希锁定旧路径的逐字节输出。演示给出
32 与 256 两档的控制点数、段号、段数与耗时。
