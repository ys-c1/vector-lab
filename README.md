# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |
| svg | demo.txt, demo.csv | 子路径解析、奇偶/非零规则填充、洞面积与逐子路径明细 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## svg 模块

`M/m/L/l/Z/z` 路径按 `M/m` 切成子路径，`Z/z` 补一条 `(当前点 → 起点)`
的闭合边；`svg_parse` 旧接口与旧 `svg_fill` 行为逐字节保持不变。

- `svg_parse_ex`：新解析接口，同时给段表与子路径视图。空路径返回
  `SVG_E_EMPTY`；子路径未闭合返回 `SVG_E_UNCLOSED`，`bad_sub` 给出子路径号
  （1 起）。新增命令仍只支持 `M/m/L/l/Z/z`。
- `svg_parse_legacy`：逐式复刻旧解析器（包括多条子路径时 `start` 不重置的
  历史行为），只额外记录子路径边界，供退化填充使用。
- `svg_fill_area` / `svg_fill_rule`：按子路径分别采样扫描线穿越点，
  奇偶规则对每条子路径的穿越数取异或，非零规则对方向求和；两者都只在
  最终判定落墨处写 255。`SVG_FILL_LEGACY` 直接调用旧 `svg_fill`，
  输出逐字节一致（测试与演示都对 3 个路径做 `memcmp` 核对）。
- 洞：子路径围出的区域内若没有任何像素被最终规则落墨，这条子路径记为洞。
  `SVGStats` 给出 `holes`、`hole_sub`（首个洞的子路径号）、`hole_area`
  （各洞子路径面积之和），以及逐子路径的 `sub_area[]` / `sub_is_hole[]`。
- `svg_fill_area` 用扫描线解析求面积：以顶点 y 与边-边交点的 y 分条，
  条内宽度随 y 线性，中点宽度乘条高即为精确值，不依赖像素尺寸。
- `make -C svg demo`：64 与 512 两档尺寸，同向/反向双环各跑奇偶与非零两规则，
  逐档给洞数、洞子路径号、洞面积、解析面积、像素计数与填充耗时；
  两规则面积差值不超过手算环面积 400；并演示空路径与未闭合子路径的报错
  子路径号。逐子路径明细导出 `demo.csv`。
