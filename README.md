# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## render 模块：哨兵填充与未初始化内存检测

导出图在不同机器间偶发差一像素，疑似未初始化内存。render 模块的所有工作缓冲区先按
哨兵值填充再计算，并提供端到端验收：

```
make -C render guard
```

会做四组场景（`render/scenes/*.txt`）的：

- **重复一致**：同一场景多次渲染逐像素比对，差异像素必须为 0；
- **哨兵无关**：用两种不同哨兵（0xA5 / 0x5A）各跑一遍，输出差异必须为 0，否则说明
  输出来自未初始化内存；同时扫描输出中残留的哨兵像素（有则说明该像素从未被写入）；
- **越界写入**：输出缓冲前后各带哨兵带，被改写即报出相对偏移；
- **正常路径不变**：`guard=off` 关闭哨兵、按原方式清零，输出须与改动前镜像逐字节一致；
- **检出能力自检**：注入"跳过某个像素写入"的真实故障，必须在该像素偏移被检出
  （检不出即失败）。

每个场景报告差异像素数、哨兵填充次数与耗时。

命令行：`render/build/cli scene.txt out.pgm w h scale [guard=off|guard=0xNN]`
（默认开启哨兵，哨兵值 0xA5；统计信息输出到 stderr，不影响图像）。
