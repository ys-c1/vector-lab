# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## stroke：自适应接法

`stroke_polyline_ex` 在 `adaptive != 0` 时对每个拐角比较斜接、斜切、圆角
三种接法相对理想扇形（半径为半宽、张角为转角）的面积误差，取误差最小者：

- 斜接 = 扇形 + 尖峰三角（窄角鼓起，转角越大误差越大）；
- 斜切 = 内接三角（削掉弓形，宽角削得多）；
- 圆角 = N 段弦对扇形的多边形逼近（`round_segs` 控制段数，为 1 时退化为斜切）。

规则：

- 选中接法的面积误差必须小于 `err_max`，否则整体返回 -5；
- 拐角为 0 度（方向未改变，无角可接）返回 -3，180 度（线段折返，接法
  未定义）返回 -4；
- 三种接法误差完全相同时固定选斜切：顶点最少、计算最简、结果确定，
  不依赖浮点偶然性；
- `adaptive == 0` 时走原来的固定接法，输出与 `stroke_polyline` 逐字节相同。

每个拐角的判定结果（接法、三种误差、耗时）写入 `SJoinReport`。
