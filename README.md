# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |
| fit | demo.txt | 枚举窗口顶点数反解最小面积误差，含停止规则与逐字节回归 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

`fit` 模块枚举正 n 边形窗口的顶点数，对每个 n 旋转扫描求最小面积误差，
按 EXACT/TOL/GAIN/CAP 规则停止；四组窗口的顶点数、面积误差、耗时见
`fit/README.md`。顶点不足三拒绝、共线顶点单独标出、面积误差限千分之一，
并保证关掉新逻辑时既有渲染产物逐字节不变。
