# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |
| render | *.pgm | 场景放置、超采样栅格化、吸附出图、PPM/PGM 导出 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## render：像素吸附步长反解

顶点吸附到像素网格能对齐像素，但会拖动面积。`render/src/snap.c` 反解量化步长：

- 候选阶梯：`h = pitch*m`（m 从粗到细），再 `h = pitch/m`（亚像素）；pitch 是一个输出像素对应的场景单位，x/y 独立。
- 准则：取**误差预算内最粗**的步长。更细的步长误差单调趋 0，若按“误差最小”求解只会退化成 h→0，所以预算作约束、最粗作目标。
- 误差：`|A(h)-A(0)| / A(0)`，面积取各多边形 `|带符号面积|` 之和；同时要求单多边形误差也在预算内。
- 拒收：吸附后退化成点 / 线段 / 零面积 / 绕向翻转，或粗于实测塌陷区间 → 该步长作废，记录拒收样本。
- 退化输入单独报告，不计入误差分母。

```
make -C render test         # 单元测试（含反解、预算、拒收、退化）
make -C render check        # 浮点路径逐字节回归（关闭 --snap 时）
make -C render scene        # 四组场景的步长 / 误差 / 耗时报告
render/build/cli scene.txt out.pgm 96 96 1.0 --snap [--ladder]
```

`--snap` 关闭时走原浮点管线，输出与改动前逐字节相同。
