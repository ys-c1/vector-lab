# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |
| merge | demo.txt | 两段多边形并集拼接：交点切分、按绕序串外环、切点/绕序报错 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## merge 模块说明

两段多边形拼接时，朴素相加会把交叠区算两次导致面积虚高。`merge_polygons` 的处理顺序：

1. **绕序检查**：两段必须同为逆时针（CCW），冲突返回 `MERGE_E_WIND`，错误信息带两段编号；
2. **切点预检**：交点处只触不穿、顶点贴边、共线重叠一律返回 `MERGE_E_TANGENT`，错误信息带两段编号与坐标；
3. **切分重叠**：在所有交点处把两段的边切开（按参数 t 排序）；
4. **串外轮廓**：丢弃中点落在对方内部的子边（边界点按严格内外处理，避免共边/凹口导致重复计数），按绕序把幸存边逐段续接成外环；
5. **并集开关**：`union_on=0` 时跳过全部几何处理，原样返回两段（逐点一致）。

返回码：`MERGE_OK / MERGE_E_ARG / MERGE_E_WIND / MERGE_E_TANGENT / MERGE_E_CAP`，
错误说明用 `merge_last_error()` 取回（含段号）。demo 对 2 段与 16 段两组分别
核对并集面积误差、外环点数（与切点配对列出）、耗时，并按段号打印拼接顺序表。
