# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |
| warp | demo.txt, fixpoint_reports.csv | 变形修正：弧长反参数化的不动点迭代收敛 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## warp 模块

把“变形修正”具体化为弧长反参数化：给定目标弧长 s，求三次贝塞尔参数 t 使 S(t)=s
（S 为自适应 Simpson 积分的累计弧长），接口见 `warp/src/warp.h`。

- 迭代式（不动点）：`t_{k+1} = clamp(t_k + ω(t_k)·(s−S(t_k))/L, 0, 1)`，L 为总弧长。
  自适应松弛 `ω(t)=min(ω_cap, 0.9L/v(t))`、`ω_cap=min(0.9, 1.8L/vmax)`，
  使 g(t)=t+ω(t)(s−S(t))/L 全局满足 `|g'|=|1−ωv/L|≤0.8<1`，即压缩映射：
  不动点唯一、任意初值线性收敛，误差界 `|t*−t_k| ≤ q^k/(1−q)·|t_1−t_0|`。
- 停止：弧长残差 `|s−S(t_k)|≤tol_len`（主，默认 1e-10）或参数步长 `≤tol_t`（次）；
  到 `max_iter`（默认 64，硬上限 4096）仍不达标返回 `WARP_NO_CONVERGE` 并拒绝出点，
  报告末轮残差与所用初值；方向反转且幅度不衰减判 `WARP_OSCILLATING`，
  单独给出振荡周期与首个触发步。
- 四组初值（0 / 0.25 / 0.5 / 1）各报迭代次数、残差、实测收敛因子 q 与耗时，
  解与初值无关；独立梯形积分（另一条计算路径）复核解点残差。
- 关掉新逻辑（`flags` 不含 `WARP_F_FIXPOINT`）时走旧路径：固定 8 次、端弦归一化、
  ω=1，无停止判据——即改动前的现状行为。`make -C warp compat` 对 4 条曲线 ×
  9 个目标 × 4 组初值比对 t 与点坐标逐位相同，并对 PGM 产物做逐字节比对
  （`tools/diff.sh`）。
