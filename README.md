# vector-lab

矢量图形小模块集合，每个模块独立构建，自带测试与演示产物。

| 模块 | 产物 | 内容 |
|---|---|---|
| bezier | demo.txt | 三次贝塞尔求值与按容差细分 |
| stroke | demo.txt | 折线描边到多边形轮廓 |
| dash | demo.txt | 虚线切分与相位控制 |
| bbox | demo.txt | 点集包围盒与旋转盒 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## render 模块：方差驱动的自适应抗锯齿

`raster_fill` 保留固定网格超采样（`ss×ss`），默认路径不变。
`raster_adaptive`（`render/src/adaptive.[ch]`）按统计方式定样本数：

1. 每像素 `pilot_n` 个抖动随机样本，逐像素用无偏估计
   `s² = h(n-h)/(n(n-1))` 估单点方差（伯努利分布），取全图最大值；
2. 按目标置信区间全宽反推 `n = ⌈4·z²·s²/W²⌉`，z 为标准正态分位数；
3. 试点方差为 0 时退化：覆盖率确定为 0 或 1，区间宽度为 0，不追加样本；
4. 所需 `n > nmax` 时拒绝渲染（返回 `RADAPT_E_REJECT`，不写缓冲区），
   并报告 nmax 下能达到的最窄宽度。

`make -C render ademo` 对四类图（轴对方形/旋转方形/三角形/十六边圆）
报告样本数、预测与实测区间宽度、耗时，并演示拒绝路径。固定随机种子，
产物可复现。
