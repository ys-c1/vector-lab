# codec

子带图像编解码器（`.sbc`）。在不改动 `render/` 现有 PGM 导出路径的前提下，
提供一条独立的高压缩率导出链路：多级整数 Haar 子带分解 → 按子带能量反解
量化步长 → 对称舍入量化 → zigzag varint → raw-deflate 熵编码。

```
make            # 构建并跑单元测试（105 项）
make demo       # 生成四类测试图并对四个质量档做基准（体积/PSNR/耗时/判定）
./build/cli enc in.pgm out.sbc {high|balanced|small|tiny}
./build/cli dec in.sbc out.pgm
./build/cli info in.sbc
./build/cli bench in.pgm [in2.pgm ...]
```

## 目录

| 文件 | 职责 |
|---|---|
| `src/wavelet.c/.h` | 多级二维整数 Haar（S 提升），原地正/逆变换，奇数边长可逆 |
| `src/quant.c/.h` | 子带能量统计、按能量反解量化步长、对称舍入量化/反量化 |
| `src/sbc.c/.h` | `.sbc` 容器、varint+deflate 编解码、严格校验、PSNR |
| `src/pgm.c/.h` | P5/P2 PGM 读写（写头部与 `render/export.c` 完全一致） |
| `cli.c` | enc / dec / info / bench 命令行 |
| `test.c` | 可逆性、纯色无损、拒零步长、损坏文件拒绝、往返一致性 |

## 通过门槛（两条件同时成立才算过）

- **体积** ≤ 现 PGM 体积的 60%（即小 ≥ 40%）；
- **PSNR** ≥ 32 dB。
- 另：纯色内容必须无损；任何步长为零或负必须拒绝；原导出路径逐字节不变。

`bench` 子命令对每个质量档直接打印 `PASS/FAIL`，两个条件与上述一致。

## 量化步长反解推导

### 1. 子带与能量

多级 2-D Haar 把图像分解为 1 个最粗低频带 LL 与每级 3 个高频带
（HL 水平细节、LH 垂直细节、HH 对角细节），共 `B = 3L+1` 个带。
对带 `b` 的 N_b 个系数 c_i，先取整数均值 μ_b，再定义零均值能量（即方差）

```
E_b = (1/N_b) · Σ_i (c_i − μ_b)²
```

- `E_b` 大 → 该带承载的细节/纹理多 → 量化误差易被看见 → **应给小步长**；
- `E_b` 小 → 该带接近平坦 → 粗量化也不可见 → **可给大步长**换体积。

### 2. 率失真意义下的反解

均匀量化器在步长 Δ 下，单系数重建误差近似均匀分布于 `[−Δ/2, Δ/2]`，
其均方误差 `D ≈ Δ²/12`，即要达到失真 D 所需步长 `Δ ∝ √D`。
在固定总码率约束下做拉格朗日最小化 `J = Σ_b D_b + λ·R_b`，对各带独立求极值，
可得经典的“能量加权”结论：**步长应与该带信号能量的平方根成反比**。
据此写出反解式（Δ0 为质量档基准步长，Emax 为所有高频带的最大能量）：

```
                ⎛  Emax   ⎞^γ
Δ_b = clamp( Δ0·⎜─────────⎟ , 1 , 8·Δ0 )
                ⎝ E_b + ε ⎠
```

- **能量高 → 比值小 → Δ_b 小；能量低 → 比值大 → Δ_b 大**，方向与要求一致；
- 指数 γ 取 **0.35**（而非满指数 0.5）。γ=0.5 对极平滑图的低能高频带反解出
  过大的步长，造成照片发糊；γ=0.35 保留单调反比关系但收紧动态范围，
  经网格扫描在照片/细节图上四档均能同时满足体积与 PSNR 门槛；
- ε=1 仅作数值稳定，防止除零；
- clamp 下界 1（Q16 定点，即步长 1/65536 的整数表示下限）保证 **Δ_b 恒 > 0**；
  上界 `8·Δ0` 防止低能带步长发散。

### 3. 零/负步长的拒绝

步长以 Q16 无符号定点存储。反解后若结果非有限、`≤ 0` 或截断为 0，
`quant_analyze` 直接返回负错误码，编码中止；解码侧读到 `step==0`
或超出 `UINT32_MAX` 的字段也一律拒绝（`rc=-14`）。基准步长 Δ0=0
在入口即被拒（`rc=-3`）。无符号类型本身不可表达负值，越界值在解析阶段拦截。

### 4. 纯色无损与 LL 保护

- 若某带所有系数相同（`Σ(c−μ)²==0`），标记为常数带，**只存均值、不量化**，
  无损直通。纯色图像的所有子带都是常数带 → 整帧无损（容器头置 lossless 位）。
- 最粗 LL 带系数极少（6 级分解后 256² 图仅 16 个系数）却主导整体重建，
  因此固定步长为 1 做无损保护，反解公式只作用于高频带。这同时保证四档
  的底色/大色块绝不偏色。

### 5. 整数 Haar 的可逆性

采用 S 提升（floor 除法，向负无穷取整）：

```
d = r − l
s = l + floor(d/2)        逆：l = s − floor(d/2), r = l + d
```

全程整数运算、无浮点舍入，正逆变换逐系数精确还原；奇数边长时末位样本
直通，同样可逆。量化是唯一的有损环节。

## .sbc 容器（16 字节定长头 + deflate 负载）

```
0..3   魔数 'S''B''C''1'
4..5   宽 BE16      6..7   高 BE16
8      分解级数(1..6)
9      bit7=lossless, bit0..3=质量档(0..3)
10..13 原始负载长度 BE32
14..15 deflate 负载长度 BE16
16..   raw-deflate 流（varint: zigzag+LEB128）
```

负载按带依次写：`[常数标志][均值][步长Q16]`，非常数带再逐系数写量化码。
解码端校验魔数、尺寸、级数、质量档、长度自洽、varint 范围与步长为正，
任何不符均返回负错误码而不产出像素。
