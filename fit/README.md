# fit

反解裁剪窗口的顶点数。固定顶点数随手取会让面积误差忽大忽小，本模块
**枚举顶点数 n**，对每个 n 在朝向对称扇区内旋转扫描，求出该 n 下的**最小
面积误差**，再按明确的停止规则选定 n。

## 模型

- 候选窗口取**正 n 边形**：圆心与外接圆半径由目标窗口的顶点质心、平均向径
  确定（对正多边形与参考圆窗口这就是精确外接圆），唯一自由度是朝向 θ。
- 目标面积 = `clip(subject, target)` 的有向面积绝对值。
- 每个 n：在一个对称扇区 `[0, 2π/n)` 内取 `ntheta` 个朝向，逐个做凸裁剪
  （Sutherland–Hodgman，与 `clip` 模块同算法，容量放宽到 `FIT_MAX=320`），
  记录最小相对面积误差 `err = |area − target| / target`。
- 参考圆窗口用 K=256 的正多边形表示，逼近真圆。

## 停止规则（为什么在某处停止改进）

| 码 | 名称 | 触发 | 含义 |
|---|---|---|---|
| 0 | EXACT | `err ≤ 1e-12` | 到达零误差地板：顶点数与目标多边形匹配；再加顶点窗口形状反而偏离，误差回升（增益转负），没有继续的意义 |
| 1 | TOL | 首个 `err ≤ 1e-3` | 光滑（圆形）目标按 O(1/n²) 收敛，过线后继续加顶点只换来亚阈值精度，边际收益约 2/n 且持续递减 |
| 2 | GAIN | 连续 3 步相对增益 `< gain_eps` | 改进枯竭的安全网：容差始终够不到时，靠增益地板收尾 |
| 3 | CAP | 触达 `nmax` 仍未过线 | 顶点数上限兜底 |

停止后仍多看 1–3 行（lookahead），把“过线后误差怎么走”打印出来佐证判断。

## 约束处理

- **顶点不足三 → 拒绝**：被裁多边形或目标窗口 `<3` 顶点直接返回负错误码
  （`-2`/`-3`），不进入枚举。
- **共线顶点单独标出**：`fit_collinear` 用归一化叉积（阈值 1e-9）逐顶点
  判定前后边是否共线；求解器把每行候选窗口的共线顶点数写入
  `FitRow.collinear` 并在 demo 表单列显示。正多边形恒为 0；退化窗口
  （边上多一个顶点）会显形成 1，demo 末尾有专门用例。
- **面积误差不得超过千分之一**：`FIT_TOL=1e-3`，测试断言四组选定结果全部
  `chosen_err ≤ FIT_TOL`。
- **关掉新逻辑逐字节不变**：固定窗口渲染走 `fit_write_pgm`，公式与
  `render` 模块完全一致；`make test` 用 `cmp` 把产物与既存 render CLI 的
  PGM（`golden/fixed_window.golden`）逐字节比对，并在 render 已构建时再与
  实时 CLI 交叉比对一次。`render`、`clip` 等既有模块源码零改动。

## 四组窗口结果（64 朝向采样，nmax=96）

| 组 | 被裁多边形 / 目标窗口 | 选定 n | 面积误差 | 停止 | 耗时 |
|---|---|---|---|---|---|
| 1 | 方块 / 圆(r=5) | 78 | 9.81e-04 | TOL | ~22 ms |
| 2 | 大多边形 / 旋转正方形 | 4 | 0.000e+00 | EXACT | ~0.1 ms |
| 3 | 三角形 / 圆(r=4) | 62 | 9.90e-04 | TOL | ~11 ms |
| 4 | 大多边形 / 正五边形 | 5 | 0.000e+00 | EXACT | ~0.1 ms |

- 组 2/4 是多边形目标：n 等于目标顶点数且朝向对齐时误差精确为零，n 再大
  误差回升——这是 EXACT 停止的直接证据。
- 组 1/3 是圆形目标：误差随 n 单调下降、O(1/n²) 收敛，在 n=78 / n=62 首次
  进入千分之一，此后每加一个顶点只多买约 2/n 的相对改进——这是 TOL 停止的
  依据。耗时为整组枚举（n=3 直到停止点）的墙钟时间。

## 用法

```
make -C fit test   # 344 项断言 + 逐字节比对
make -C fit demo   # 四组完整枚举表、拒绝/共线用例，写入 demo.txt
```
