# winnorm

窗口顶点绕序归一化：自交检测 → 拆分子环 → 按子环面积符号定向 → 统一绕序。

## 问题

窗口顶点常常是"顺手写"的：有的顺、有的逆，有的还自交。自交时鞋带公式的
**整环**有符号面积会随顶点顺序时正时负，单看整环符号会骗人：

| 窗口 | 顶点顺序 | 整环有符号面积 | 拆开后子环面积 |
|---|---|---|---|
| W1 矩形 | 逆时针 | +640 | +640 |
| W2 矩形 | 顺时针 | −640 | −640 |
| W4 蝴蝶结 | 自交 | 0（骗人） | +192, −192 |
| W6 双环 | 自交 | 0（骗人） | +64, −128, +64 |

## 处理顺序

1. **自交检测**（`winnorm_check`）。只有两条非相邻边在各自内部**真穿过**
   才算自交；顶点落在别的边上、共线重叠单独分类（`WN_TOUCH_VERTEX/OVERLAP`）；
   相邻边共用端点不算。检测用双精度叉积，判定容差随坐标量级放大
   （`WN_EPS` 绝对下限 + `WN_REL` 相对项），避免近共线被误判。
2. **拆分**（`winnorm_split_self`）。做**平面排列**而不是"切一刀再各自
   递归"：在所有真穿过处切开两条边，建半边结构、按极角排序、追踪每个面；
   面是否填实由**输入环的环绕数**决定（奇偶规则下奇数才填）。这一步保证：
   - 每个子环都是简单环；
   - 子环之间没有真穿过（只可能共顶点或共边）；
   - 并集覆盖与输入逐点一致（拆分只加交点顶点，不改覆盖）。

   用环绕数而非面积来分类，是因为拆开后面被覆盖两次的区域（五角星中心、
   嵌套且原方向相反的子环）在奇偶规则下是洞，不能算作一个正向子环。
3. **定向**。按每个子环自己的有符号面积定方向：正为逆时针、负为顺时针、
   零为退化拒绝。符号只用来决定"要不要翻"，不用来相信输入。
4. **统一绕序**。需要翻转的子环整环逆序（首点不动），使每个子环有符号
   面积为正。逆序不改变顶点集合，几何不变。

### 面积绝对值为什么恒不变

翻环只是把顶点序列倒过来。鞋带项 `t_i = fl(ax·by) − fl(bx·ay)` 在逆序后
变成 `−t_i`（乘法交换、减法对操作数取负精确对称）。精确求和
`winnorm_signed_area_exact` 把正项、负项分开按 |值| 升序累加：

- 取负不改变每堆内部排序后的数值序列；
- 同号序列逐项取负，部分和互为精确相反数（IEEE 加法对全操作数取负对称）；
- 最后 `P' + N' = (−N) + (−P) = −(P + N)`，0.5 乘是精确二进制缩放。

所以翻前翻后的 |面积| 逐位相同，偏差恒为 0，与坐标数值无关。
归一化时还会在翻转后**复算一遍**，若逐位不同则返回 `WN_ERR_AREA_DRIFT`，
而不是悄悄交出一个变了的结果。

## 拒绝规则（都带序号）

| 情形 | 错误码 | 序号 |
|---|---|---|
| 自交未拆分（窗口文件没有声明拆分） | `WN_ERR_SELF_CROSS` | 两条边号 |
| 重复点（相邻重合或任意两处重合） | `WN_ERR_DUP_POINT` | 第一个重复点下标 |
| 顶点贴边 / 共线重叠（拆分也消不掉） | `WN_ERR_CONTACT` | 两条边号 |
| 子环面积为零 | `WN_ERR_DEGENERATE` | 子环号 |
| 翻转前后面积绝对值不再逐位相同 | `WN_ERR_AREA_DRIFT` | 子环号 |
| 顶点不足 / 超上限 / 子环超上限 | `-2 / -3 / -8` | — |

自交窗口"已拆分"的表达方式是窗口文件里的 `S <窗口号> <边a> <边b>` 声明；
没有声明的窗口按 `allow_split=0` 走，遇到自交即拒——这正是"自交未拆分"。

## 跑一遍

```sh
make -C winnorm test      # 单元检查（含五角星 5 交点、逐位面积不变量）
make -C winnorm verify    # 四组窗口报告 + 拒绝用例 + 面积/几何不变量 + 逐字节回归
make -C winnorm demo      # 关/开新逻辑对照
```

`verify.sh` 的四段：

1. 四组窗口逐窗口报告：子环数、绕序符号、翻转数、面积绝对值合计、前后偏差
   （必须为 0）、耗时；
2. 拒绝用例：蝴蝶结/双环未拆分、重复点、顶点贴边，全部退出码 1 且带序号；
3. 面积绝对值不变量与几何不变：TSV 逐项检查
   - 拆分前后、翻转前后的 |面积| 合计逐位相同；
   - 从归一化后的顶点用 long double **外部复算**的 |面积| 与模块结果一致；
   - 在 61×61 采样点上，原输入的奇偶覆盖与归一化子环并集的奇偶覆盖逐点相同；
4. 关掉新逻辑：`baseline/legacy.c` 是 render 模块旧路径的逐字节副本，
   生成的 `baseline/legacy.pgm` 与 `build/run render` 的 mode=0 输出
   **逐字节相同**（`tools/diff.sh` 验证），新路径图与老路径图也相同。

## 窗口文件格式

```
W <窗口号>                     窗口头，号码唯一
x y                            顶点，每窗口至少 3 个
S <窗口号> <边a> <边b>          拆分声明：在边 a 与边 b 的交点切开
# 注释
```

样例由 `tests/gen_windows.py` 纯 Python 生成（不调用被测代码），
四个窗口坐标互不重叠，画布包围盒取全部输入顶点并集。

## 文件

| 文件 | 作用 |
|---|---|
| `src/winnorm.c/h` | 检测、平面排列拆分、定向、精确面积 |
| `src/winsplit.c/h` | 窗口文件装载 + 按 `S` 声明拆分（独立实现，交叉核对） |
| `src/winsolve.c/h` | 批量归一化、画布包围盒、双路径出图、PGM 导出 |
| `run.c` | 驱动：`report`（逐窗口报表）与 `render`（双路径出图） |
| `demo.c` | 关/开新逻辑对照 |
| `baseline/legacy.c` + `baseline/*.pgm` | 关掉新逻辑的逐字节基线 |
| `tests/gen_windows.py` | 四组窗口与拒绝用例数据生成 |
| `verify.sh` | 端到端验证 |

## 接口要点

- `winnorm_normalize(win, n, allow_split, &out, &at, &at2)`：一站式入口。
  `allow_split=0` 时自交即拒；非 0 时先拆再定向。
- `winnorm_split_self`：只拆分，不定向。
- `winnorm_normalize_ring`：只处理已简单的单环。
- `winnorm_signed_area_exact`：符号分堆、升序累加的精确求和；
  `winnorm_signed_area` 仍可直接用于报表。

## 出图口径

老路径（mode=0，`render` 模块的 `raster_fill`）用奇偶规则。归一化后的子环
全部逆时针，如果下游改用非零环绕，被覆盖两次的区域会被填实、原图却是洞——
那才是真正的几何改变。因此 `ws_render` 的新路径（mode=1）把**所有子环的边
并成一个边集**后仍按奇偶覆盖，这样与老路径逐字节相同是严格结论；统一后的
绕序作为数据交给下游，由下游按自己的填充规则使用。
