# snap：反解等分总长，让等分点落在整点

## 问题

折线按累计弧长等分：第 k 个点位于 `s_k = k*d`，共 m 个点，总长
`L = (m-1)*d`。默认的小数等分取 `d = T/(m-1)`（T 是折线总长，L = T），
点几乎必然带小数；导出时逐点取整，误差逐点累积，最后一段尤其明显。

## 反解

把 d 当未知量，在

```
d ∈ [T/m, T/(m-1)]        即  (m-1)/m * T <= L <= T
```

内搜索。下界保证最后一段不超过间距 d（不会多出第 m+1 个点），上界保证
目标总长不超过折线总长。取整误差 `ex = x - round(x)`、`ey = y - round(y)`，
误差 `e_k = hypot(ex, ey)`，目标函数按字典序最小化：

1. 半像素违反量 `max(0, max_e - 0.5)` —— 硬约束优先
2. 全部落在整点（`max_e <= 1e-6`）优先
3. 最大欧氏取整误差 `max_e`
4. 均方根取整误差 `rms_e`
5. `-L` —— 同误差下总长取最长

候选来源：整数格点穿越（点落在 `x=const` 或 `y=const` 上的弧长，按
`d = s/k` 反解）、折线顶点落在格点时的 `s/k`、全区间 2048 点粗网格，
再从若干最优起点做 25 点 × 7 轮局部收缩；评价时对当前最优做早停剪枝。

## 四组结果

`make -C snap bench`（`snap/bench_out/metrics.log` 有完整表格）：

| 组 | 形状 | m | 折线总长 T | 目标总长 L* | 覆盖率 | 状态 | 最大取整误差 | 耗时 |
|---|---|---|---|---|---|---|---|---|
| g1_axis | 整数格点轴向折线 | 104 | 1350.000000 | 1339.000000 | 0.9919 | EXACT | 0.000000 | ~2.2 ms |
| g2_diag345 | 3-4-5 斜边 | 12 | 900.000000 | 880.000000 | 0.9778 | EXACT | 0.000000 | ~0.45 ms |
| g3_mixed | 45° 与轴向混合 | 8 | 1195.979797 | 1053.482323 | 0.8809 | EXACT | 0.000000 | ~0.18 ms |
| g4_skew | 30° 斜向 | 8 | 1000.000000 | 994.147873 | 0.9941 | NEAREST | 0.085374 | ~0.28 ms |

`g2` 与 `g4` 的小数等分本身就越过半像素（0.530087、0.527468），反解把
`g2` 拉到全整点；`g4` 的 30° 斜向不存在全整点解，给出最接近方案
（0.0854，远低于半像素）。四组结果都用独立的全区间暴力（400 万点网格 + 局部收缩）核对过最优性；
`over-budget` 的 (0,0)-(1,1)-(2,4)、m=7 也确认任何 d 都超出半像素。

## 拒绝与"最接近"

- **起点终点重合**：`SNAP_E_CLOSED`，stderr 打印 `REJECT closed:` 与重合点坐标。
- **零长线段 / 总长为零**：`SNAP_E_DEGENERATE`，`REJECT degenerate:`。
- **m < 2**：`SNAP_E_ARG`（参数 m）。
- **半像素内无解**：状态 `OVER_BUDGET`，仍输出最接近方案，退出码 3。
  例：折线 `(0,0)-(1,1)-(2,4)`、m=7，最优最大误差 0.653784（任何 d 都越界）。

## 关闭新逻辑

`SNAP_DISABLE=1 snap <line> <m>`（或 `--legacy`）走旧的小数等分，代码路径
与原 `gold/ref points` 的公式逐表达式一致；`bench.sh` 对四组路径都做了
与 `gold/ref points` 的**逐字节**比对（`cmp`），全部 IDENTICAL。

## 用法

```
make -C snap test                 # 87 项单元检查
make -C snap bench                # 四组基准 + 与 gold 的逐字节比对 + 拒绝情形
snap/build/snap snap/data/g2_diag345.txt 12 --nodes out.txt
snap/build/snap snap/data/g2_diag345.txt 12 --legacy    # 关闭新逻辑
snap/build/snap --self            # 目标函数与拒绝情形自检
```

`--nodes` 落盘每行：`x y rx ry ex ey err`（原始、取整、误差）。
