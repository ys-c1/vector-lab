# blend

把每一层混合模式表示成颜色上的仿射矩阵（齐次坐标 4×4，实际为三通道独立的 2×2
分块对角），混合链就是矩阵连乘；给定目标颜色时枚举层的全排列，用 CIE76
Delta E 做色差，反解出连乘顺序。

## 矩阵形式

底色 `c`、层源色 `s`（每通道独立，取值 0..1），层作用 `c' = a*c + b`，
在 `(r,g,b,1)^T` 下为 4×4 矩阵：

| 模式 | a | b | 可逆条件 |
|---|---|---|---|
| normal | 0 | s | 恒奇异，拒绝 |
| multiply | s | 0 | s ≠ 0 |
| screen | 1−s | s | s ≠ 1 |
| plus | 1 | s | 恒可逆 |
| exclusion | 1−2s | s | s ≠ 0.5 |

以下模式是分段/非线性的，**没有矩阵形式**，出现在链中直接拒绝
（`blend_solve` 返回 -11，`bad_step` 给出层索引）：

| 模式 | 公式 | 为什么不可逆 |
|---|---|---|
| difference | `|c−s|` | 分段绝对值，单输入对两个输出 |
| darken | `min(c,s)` | 分段，区间坍缩 |
| color-dodge | `c/((1−s)(1−c))` | 非线性有理函数 |

仿射模式在某通道系数 `a=0` 时该通道行列式为 0，返回 -10 并通过 `pivot`
报告失效通道（如 multiply 源色为 0、screen 源色为 1、exclusion 源色为 0.5）。

## 反解

`blend_solve` 用标准迭代 Heap 算法枚举全部 n! 个排列（n ≤ 8），对每个排列
前向合成并计算与目标的 Delta E，返回色差最小的顺序。

- 全部排列色差都大于容差 `tol`：返回 -12，解结构里仍带最优顺序与色差。
- 单层（n=1）：不搜索，直接输出，`*single` 置 1。
- 色差在 Lab 空间计算（sRGB 先线性化、转 XYZ/D65、再转 Lab）。

## 固定顺序回归

`BLEND_FIXED=1` 时 demo 只走按声明顺序的纯前向路径（不调用任何求解逻辑）。
`make regress` 将其输出与 `golden/fixed.txt` 用 `../tools/diff.sh` 逐字节
比对；新逻辑关闭时输出必须字节不变。

## 命令

```
make test     # 115 项单元检查（含独立 W3C 公式参照交叉验证）
make demo     # 四组场景：A/B 可逆链反解，C 非线性拒绝，D 奇异拒绝，E 单层
make regress  # 固定顺序快照逐字节比对
```
