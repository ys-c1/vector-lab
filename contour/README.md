# contour

多层嵌套轮廓的逐层核验。针对“多层轮廓只看得到最外一圈”的问题：每层的
顶点与面积写进同一个文件，逐层用独立参照 `gold/ref area` 量面积。

## 输入格式

```
L 0          # 层头，层号必须从 0 起连续递增，跳号拒绝并指出期望层号
x y          # 顶点行，每层至少 3 个点
...
L 1
...
```

空行跳过；层头/顶点行的任何多余 token、层头之前出现顶点、行超长，一律
按格式错误拒绝。

## 拒绝规则（均带层号）

| 错误 | 码 | 报告层号 |
|---|---|---|
| 点全共线（含全重合） | `CT_ERR_COLLINEAR` | 该层 |
| 不足三个点 | `CT_ERR_TOOFEW` | 该层 |
| 层号跳号/乱序/不从 0 起 | `CT_ERR_GAP` | 期望出现的层号 |
| 面积未随层号单调不增 | `CT_ERR_MONO` | 第一个违例层 |
| 堆内存超过输入 6 倍 | `CT_ERR_MEM` | — |

面积用鞋带公式（与 gold 的 256×256 数格子算法独立），demo 再逐层调
`gold/ref area` 交叉核对：相对偏差超 5% 拒绝，gold 面积序列同样要求
单调不增（带 0.1% 网格噪声带）。

## 内存

整文件缓冲 + 按实际顶点数一次性分配的点池（16 字节/点），无逐点/逐行
扩容。文本格式每点至少 5 字节，结构上限即 < 5× 输入；另有 6× 硬性检查
兜底，峰值记录在 `CTSet.peak_bytes`。

## 用法

```
make test     # 33 项单元检查（含全部拒绝路径与层号）
make demo     # 解析 data/sample.txt，写 layers.txt，逐层调 gold 量面积
make bench    # 两档点数：small 4 层×64 点 / large 8 层×1024 点，
              # 各报层数、最佳毫秒数、内存倍率
```
