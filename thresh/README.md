# thresh

灰度图亮像素占比验收工具：把亮像素占比写成阈值的单调函数并反解达标阈值。

## 数学定义

对 8 位灰度图（PGM P5，maxval=255），阈值 `t` 下的亮像素占比为

```
F(t) = #{像素 gray : gray >= t} / N
```

`F(t)` 在 `t ∈ [0,256]` 上关于 `t` **单调不增**，是只取有限个值的阶梯函数：

- `F(0) = 1`（全部像素都亮）
- `F(256) = 0`（没有像素达到 256）
- 整数阈值 `t ∈ [0,255]` 即灰度范围内的全部合法取值

给定验收区间 `[lo, hi]`，反解就是在阶梯上找一个落在区间内的台阶：
从高阈值向低阈值扫描，取**首个**达标阈值（满足条件的最大阈值，二值化最保守）。

## 拒绝规则

- **目标落在台阶空隙**：需要的阈值不是整数灰度值（两档灰度之间），返回 `UNREACHABLE`，
  并报告目标两侧最近的可达占比台阶。
- **目标越出 F 的整体范围**（如要求占比 0 而图中无任何 t≤255 能清零，或要求占比超过 F(1)）：
  等效于阈值超出灰度范围 `[0,255]`，同样拒绝。
- **纯黑图**：F(t) 恒为 0，单独报 `PURE-BLACK`，不参与反解。
- **纯白图**：F(t) 恒为 1，单独报 `PURE-WHITE`，不参与反解。

## 命令

```
thresh fixed <in.pgm> <out.pgm> <threshold 0..255>   # 固定阈值（旧逻辑）
thresh solve <in.pgm> <out.pgm> <lo> <hi>            # 单图反解
thresh batch <manifest> <outdir>                     # 批量验收
```

清单每行 `name path lo hi`，`#` 起始为注释。每张图报告：
阈值、实际亮像素占比（必落在给定区间内）、耗时（毫秒）。
退出码：0 全部达标；3 区间非法；4 越界/不可达；5 纯黑或纯白。

## 逐字节兼容

`fixed` 是关掉新逻辑时的旧路径：`gray >= t → 255，否则 → 0`，
同一输入同一阈值多次运行输出逐字节一致（`make demo` 用独立 Python 参照做字节比对）。

## 演示四类图

`make demo` 生成并验收：

| 图 | 灰度分布 | 目标区间 | 结果 |
|---|---|---|---|
| gradient | 0..255 宽分布 | 0.30~0.32 | 反解成功 |
| bimodal | 仅 64/192 两档 | 0.30~0.35 | 台阶空隙，拒绝 |
| black | 全 0 | 0.30~0.32 | 纯黑，单独报告 |
| white | 全 255 | 0.30~0.32 | 纯白，单独报告 |
