# peel

凸层逐层剥离（洋葱剥皮）。多层轮廓只给最外一圈时，描边分不出层次；
这里把点集逐层剥开，每层记面积，再反解“覆盖 95% 面积要剥到第几层”。

## 算法

1. 输入点按坐标精确去重；记下去重前后点数。
2. 对当前剩余点求逆时针凸包（Andrew 单调链，严格顶点）。
3. 记下本层凸包面积。
4. 把落在凸包边界 `eps` 带上的点全部移出——既包括凸包顶点，也包括
   恰好压在边上的共线点；`eps = 1e-9 × 包围盒对角线`，由各边点的
   **到线段**距离判定（不是到无限直线）。
5. 对剩余点重复。

因为每轮的剩余点集是上一轮的子集，后一层凸包含于前一层，面积
天然随层号单调不增；实现里仍逐层核对，回升即报内部错误。

停止与拒绝都带层号：

| 情形 | 结果 |
|---|---|
| 剩余点不足三点 | 拒绝，报该层层号（首层即拒时 `peel_run` 返回 3） |
| 剩余点全共线，凸包面积为零 | 拒绝，报该层层号（首层即拒时返回 2） |
| 层数超过调用方容量 | 拒绝，报该层层号，返回 -4（不静默截断） |
| 点正好剥完 | 正常结束，`stop_layer` 记在剥完后的下一层 |

## 反解

定义剥离第 `1..k` 层后的剩余面积 = 第 `k+1` 层凸包面积（末层剥完记 0）。
返回最小的 `k`，使 `剩余 / 第 1 层面积 <= 1 - frac`；`frac=0.95` 即要求
剩余不超过 5%。

## 跑一遍

```sh
make -C gold                 # 参照
make -C peel test            # 单元测试
make -C peel run             # 四个场景
```

`make run` 的产物在 `peel/out/`（已 gitignore）：

```
out/random/{points.txt,report.tsv,layers/L01_rem.txt,L01_hull.txt,gold/L01_*...}
out/collinear/  out/dup/  out/rings/
out/summary.tsv
```

`out/summary.tsv` 每个场景一行：点数、去重点数、层数、反解层号、
剩余占比、剥层耗时、停止层号与原因、状态。

`report.tsv` 每层一行：进入点数、凸包顶点数、移出点数、面积、参照面积、
相对差、耗时。

## 参照与容差

- **主参照 `ref trap`**：按顶点 y 坐标把多边形切成横条，条内无顶点，
  宽度函数对 y 线性，取条中点即精确。简单多边形上精确到舍入，
  用作 1e-4 判据。
- **旁证 `ref area`**：仓库原有的 256×256 数格子，本身采样误差就有
  1e-3 量级，只打印相对差供参考，不参与判据。

层面积与主参照的相对差必须 `<= 1e-4`（万分之一），超标即判失败、
退出码 1。
