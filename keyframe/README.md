# keyframe

关键帧之间的中间点按最小作用量排：把加速度平方沿时间积分

```
S = ∫ |q''(t)|^2 dt
```

当作作用量，固定各关键帧的时刻与位置，解出让整段 S 最小的中间采样点。
线性插值的速度在每段内恒定、在关键帧处跳变，加速度是冲激；最小作用量
解把拐角分摊到前后两段，所以动作不会再一顿一顿。

## 离散形式

节点布局：每两个关键帧之间均匀插入 `levels` 个间隔（`levels` 取 2..16），
关键帧落在段首节点上，段内其余节点是自由未知量。每个节点 k 的加速度用
中心差分：

```
v_k^- = (q_k - q_{k-1}) / h_{k-1}
v_k^+ = (q_{k+1} - q_k) / h_k
a_k   = 2 (v_k^+ - v_k^-) / (h_{k-1} + h_k)
```

每段长度上对 a² 取梯形积分，得 `w_k |a_k|²`，`w_k = (h_{k-1}+h_k)/2`。
整段作用量 `S = Σ w_k |a_k|²` 是未知节点的对称正定二次型，x、y 各解一次
线性方程组（稠密 Cholesky）。关键帧是硬约束，直接代进右端；首末节点没有
加速度项（端点权为零）。

作用量按节点的加速度项归段：关键帧节点被前后两段共用，该项对半计入
两段，所以各段份额之和恰好等于整段 S。

## 中间点

每段取时间中点 `t = (t0 + t1)/2`：

- `levels` 为偶数时中点正好是节点，直接取该节点的平滑位置；
- `levels` 为奇数时取中点两侧平滑节点的线性插值（`f = 0.5`），不引入
  新的自由度。

## 中间点的数值特性

最小作用量解会让中间点略微越过原折线（比如 square 第 0 段中点的 y 是
-1.14，比两端的 y=0 还低），这是把拐角加速度摊到前后两段所必需的。
如果下游需要严格落在关键帧包围盒里，请自行夹取——库不做这件事，
以免破坏「整段作用量最小」这一目标本身。

## 拒绝与退化

| 情况 | 返回码 | err_at |
|---|---|---|
| 首帧或末帧时刻/坐标非有限（端点缺失） | `KEY_E_ENDPOINT` | 0 或 n-1 |
| 时间倒置或相邻时刻相等 | `KEY_E_TIME` | 第一个出错帧号 |
| 中间帧非有限 | `KEY_E_NONFINITE` | 出错帧号 |
| 帧数 < 2 或超过 16 | `KEY_E_FEW` | 传入帧数 |
| levels 越界 | `KEY_E_LEVELS` | -1 |
| 未知 flags 位 | `KEY_E_FLAGS` | -1 |
| 方程组非正定（数值退化） | `KEY_E_SOLVE` | -1 |

检查顺序：端点缺失 → 中间帧非有限 → 时间严格递增。端点先报是因为
首末帧缺失比笼统的非有限更具体，NaN 也会让后续单调性比较失去意义；
时间用严格递增（`t[i] > t[i-1]`），相等即拒。

**只有两帧**：没有内部节点可调，作用量最小解就是直线本身，平滑解与线性
解逐位相同。此时 `KeyPlan.degenerate = 1`、每段 `KeySpan.degenerate = 1`，
作用量与降幅都为 0，中点即线性中点，不报错。

## 关闭新逻辑

编译期 `-DKEYFRAME_MIN_ACTION=0` 后，`key_solve_default` 退回纯线性插值：
全部节点与中点都由两端关键帧按 `f = (t - t0)/(t1 - t0)`、
`q0 + (q1-q0)·f` 直接算出，与线性路径同一算式、同一运算顺序，逐位相同。
注：本仓库此前没有插值模块，这里的「旧输出」指线性插值这条兼容路径
自身的输出约定（节点按段内比例铺开、中点取线性中点）。

`make compat` 把 `baseline/linear_ref.c`（与本模块毫无共享代码的独立
参照实现）编成参照程序，用四个固定用例（等距/不等距时间、2 帧退化、
两档 levels）比对节点表与中点，双方按 `%.17g` 打印后逐字节核对；同时
断言关闭时两轨作用量完全相等、降幅为 0。

## 用法

```
make test     # 180 项单元检查
make demo     # 四个动作逐段中间点/作用量/降幅/耗时，导出 keyframe_spans.csv
make compat   # 关闭新逻辑的逐字节回归
```
