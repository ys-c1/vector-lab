# render

场景光栅化：场景（多边形集合）经仿射放置、窗口映射后超采样填充 PGM。

| 产物 | 内容 |
|---|---|
| `make test` | 模块与区间算术单元测试 |
| `make build/cli` | 场景文件渲染成 PGM 的命令行 |
| `make audit` | 四组场景的区间算术误差审计 |

## 区间审计（interval / iaudit）

浮点直算路径（`pipeline.c`、`raster.c`）保持原样，审计代码不被渲染调用，
关闭新逻辑时输出逐字节不变（可用 `tools/diff.sh` 与 HEAD 构建比对）。

- `src/interval.[ch]`：向外舍入的双精度区间。每次运算先按 `fesetround`
  做有向舍入，再把两个端点各向外扩 1 ulp，保证真值必在区间内；硬件有向
  舍入对 `10/64` 这类结果两端相同，不扩 ulp 会得到假零宽度区间。
- `src/iaudit.[ch]`：按浮点直算的同一条运算链分四阶段重算区间——
  `trig`（cos/sin）、`affine`（顶点仿射）、`window`（窗口跨度与 dx/dy）、
  `sample`（采样点世界坐标）。每个标量输入按 ±1 ulp 建模，故区间宽度是
  “输入舍入 + 逐运算舍入”的总误差上界。
- 经验校验：8 个标量输入各做 ±1 ulp 扰动，用最近舍入重跑整条链，检查每个
  扰动输出都落在对应区间内（`contain` 列），即最坏偏差必须在上界内。
- 截断拒绝：严格非零的操作数区间在乘法/除法中触发 `FE_UNDERFLOW` 且出现
  零端点时返回 `IVL_TRUNC`，整组场景拒绝并报告失败阶段。跨零区间（如
  输入 0 的 ±1 ulp 模型）被舍到零是合法包围，不判截断。
- 一成画面告警：任一行阶段的像素偏差上界超过短边的 10% 时置 `over_tenth`。

`make audit` 对四组场景各报每阶段的区间宽度、最坏偏差上界、经验偏差、
包含性、像素上界与整组耗时：

1. `basic` 普通坐标的健康基线；
2. `bigcoords` 1e8 量级坐标，误差沿仿射链放大但未截断；
3. `cancel` 1e15 量级窗口两端相减的灾难性抵消，上界超画面一成并告警；
4. `truncate` 次正规顶点乘 0.25 下溢，affine 阶段截断、整组拒绝。
