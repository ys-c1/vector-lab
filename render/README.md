# render

场景 → 变换 → 栅格化 → PGM。出图尺寸 `(w,h)` 与超采样 `ss` 是两个独立旋钮，
本模块在给定采样预算内反解二者的最优搭配。

## 构建与验证

```sh
make -C render test      # 单元测试（含单调性、越界分类）
make -C render verify    # 端到端：旧链路逐字节 + 四档预算曲线 + 拒绝路径
```

`verify` 依赖 `baseline/*.pgm`（旧实现的产物快照），不要随意重生成。

## 两条互不干扰的路径

**旧路径（固定搭配）** —— 位置参数调用，与原实现逐字节一致：

```sh
./build/cli scene.txt out.pgm w h scale   # 固定 ss=4、二值填充
```

`verify` 第 1 段对 5 个（场景, 尺寸, 缩放）组合做字节比对，任何改动都
会被 `tools/diff.sh` 同款的差异偏移报出来。新逻辑只在新入口启用，
旧入口根本不经过它。

**新路径（预算分配）** —— 尺寸与 ss 由分配器决定：

```sh
./build/cli --budget N scene.txt out.pgm [--ref R]
./build/bench scene.txt 0,4096,16384,65536,262144
```

## 代价模型

```
cost = w * h * ss * ss
```

`w*h` 是输出像素数，`ss*ss` 是每像素子采样数，相乘等于实际采样次数。
两个旋钮吃同一份预算，本任务就是要把这份预算切开。

## 锯齿指标 J

在固定显示网格（最长边 `--ref`，默认 256 像素）上比较：

```
J = mean|放大后的渲染 - 精确覆盖率|  +  w · mean|二阶差分|
```

- 精确覆盖率 = 场景与每个显示格子的精确相交面积 / 格子面积
  （Sutherland–Hodgman 精确裁剪；逐多边形求和后截断到 1）。
- 第二项是显示网格上的阶梯能量，直接度量边缘锯齿。
- 网格取 2 个亚像素相位（原相位 + 半格）求平均，避免"尺寸整除网格"白得对齐红利。

**为什么固定显示网格**：不固定的话"像素越多越好"，超采样永远分不到
预算。固定之后，尺寸不足会放大出块状阶梯，超过网格后收益递减，
而超采样直接提高灰阶精度 —— 两者才开始真正竞争。J 小即好。

## 单调性的来源

候选集 = `{ (w,h,ss) : w*h*ss*ss <= 编译期上界 }`，尺寸走 1.2 公比阶梯，
`ss∈1..8`。预算只负责筛掉超支候选，**不改变候选集**；预算变大时可行集
只增不减，上一档赢家仍在其中且 J 已缓存，所以 `min J` 单调不升是结构
保证，不是调参结果。`bench` 会逐行打印 `monotone` 并在违反时以非零退出。

## 越界拒绝

`--check w h ss budget` 按项判定并说明超在哪：

| 情况 | 返回 | 说明 |
|---|---|---|
| `w*h > budget` | `OVER_SIZE` | 尺寸本身超支，报超出量 |
| `w*h <= budget` 但 `w*h*ss² > budget` | `OVER_SS` | 加超采样后才超支，报超出量 |
| `ss` 不在 1..8 | `OVER_RANGE` | 超采样倍数越界 |
| 尺寸超支且 ss 越界 | `OVER_BOTH` | 两项都报 |

预算为 0（或负）→ `BUDGET_ZERO`，CLI 退出码 3，**不写图**。
预算太小放不下最小候选 → `NO_FIT`，退出码 4。

## 文件

| 文件 | 作用 |
|---|---|
| `src/alloc.c/.h` | 候选表、精确参照、J、分配、越界检查 |
