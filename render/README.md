# render

场景光栅化与 PGM 导出。

- `scene`：多边形场景与包围盒
- `raster`：超采样填充（4x4）
- `pipeline`：放置变换（平移/旋转/缩放）+ 光栅化
- `export`：P5 灰度 PGM 导出，`export_pgm_bytes(w,h)` 给出给定尺寸的精确文件字节
- `fit`：按字节预算反解最大尺寸并做可辨认判定

## 用法

```
cli scene.txt out.pgm w h scale [budget]
```

- 不传 `budget`：固定尺寸模式，与历史行为完全一致（逐字节不变）。
- 传入 `budget`：预算模式。以 `min(w,h)` 为最大边长 `cap`，在
  `PGM 字节 = 头部字节 + size*size <= budget` 约束下二分取最大方形边长。

### 可辨认判定

以 `cap` 满幅渲染为参考：点亮像素密度低于参考密度的
`FIT_RECOG_DENSITY_RATIO`（0.5）即判不可辨认；同时向上搜索并报告
仍可辨认的最小边长 `min_size`。最大合规尺寸不可辨认时**拒绝写出**，
返回 `FIT_NOT_RECOGNIZABLE` 并给出下限。

### 边界状态

| 状态 | 触发条件 |
|---|---|
| `budget-below-header` | 预算小于最小 PGM 头部（1x1 头部 11 字节），报出头部字节 |
| `no-size-fits-budget` | 预算够头部但不够任何像素负载（1x1 需 12 字节） |
| `not-recognizable` | 最大合规尺寸下图形已不可辨认，报 `min_size` 下限 |

## 四档预算实测（square 场景，cap=128）

| 预算上限 | 选中边长 | 实际字节 | 不超预算 | 可辨认 | 耗时(s) |
|---|---|---|---|---|---|
| 200 | 13 | 182 | 是 | 是（实心方块） | 0.0020 |
| 1000 | 31 | 974 | 是 | 是 | 0.0021 |
| 5000 | 70 | 4913 | 是 | 是 | 0.0027 |
| 50000 | 128（顶到 cap） | 16399 | 是 | 是 | 0.0041 |

头部不足报错、图形消失拒绝及下限正确性。
