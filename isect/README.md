# isect 线段求交：反解容差

固定容差的两难：定小了近失/抖动对漏判，定大了候选爆炸、把无关段吸进来。
本模块不写死容差，而是从数据**反解**出满足零漏判的最小容差，并证明再小就漏。

## 思路

1. **真值独立于管线**：`gold/ref.c` 把 6 位小数输入按 1e6 放大成定点整数，
   用 `__int128` 精确定向谓词判交（真交、端点接触、共线重叠、点在线上、点相等），
   全程不经过浮点。`gold/verify.py` 用独立的 `Fraction` 有理数实现交叉验证，
   两者结论必须逐对一致。
2. **距离谓词**：主管线 `isect_gap()` 返回两线段最小欧氏距离，不含任何固定阈值。
   非平行段求无限直线交点参数 (t,u)，在区间内即 gap=0，否则钳制参数取最近点距离，
   并与四端点垂距取 min（近平行稳健）；平行段判共线重叠或端点垂距。
3. **容差反解**：设真值对的最大 gap 为 `eps_req`（绑定对给出），它就是零漏判的
   数学下界。扫描从 1e-15 起按半对数网格单调上升，取第一个漏判为 0 的网格点，
   再在相邻网格档间二分 200 次收敛到 `eps_star`。
4. **「再小就漏」证明**：绑定对 gap 恰为 `eps_req`；把容差下调一个 ULP
   （`nextafter`）后该对落到容差外，漏判数 >= 1（报告 `proof_below` 行）。
5. **一成红线**：`cap = 0.1 * 最短非退化段长度`。`eps_req > cap` 则 REJECT，
   说明要零漏判就得容忍超过线长一成的吸附，不可接受。
6. **退化零长段**：设计身份由 `manifest.txt` 记录（加噪后坐标不再相等也仍标记），
   全程单独统计 `zero_segs / zero_pairs / zero_truth / candidate_zero_pairs`。

## 四组线段集

| 数据集 | 段数 | 真值对 | 零长段 | 几何构成 | 结论 |
|---|---|---|---|---|---|
| A_general | 250 | 50 | 0 | 25 相交 + 25 平行近失真值（缝 0.08）+ 25 近失非真值 + 100 填充 | ACCEPT |
| B_grazing | 180 | 60 | 0 | 大坐标 1e6、近掠角 0.01rad，相交 + 平行近失（缝 1.2/8） | ACCEPT |
| C_endpoint | 80 | 37 | 6 | T 接、水平共线重叠、端点相碰、零长点在线上 | ACCEPT |
| D_snapbig | 64 | 32 | 4 | 短段（3~5）大噪声 0.7，gap 被撑过一成线 | REJECT |

`snap.txt` 是 gold 的吸附口径：设计缝隙在 snap 内的近失对保留为真值（表达
「几何意图相交但输入带错位」），snap 外为非真值（容差过大就误吸成假候选）。

## 用法

```sh
make test     # 单元测试（含 legacy 三函数 + gap 距离谓词）
make run      # 全流程 + 硬断言（漏判为零 / 边界证明 / legacy 逐字节 / gold 双实现一致）
make demo     # 原演示，行为不变
```

产物：`report.txt`（四组反解报告）、`build/*.gold`（精确真值）、
`build/*_tbl`（交点表）、`data/*/sweep_result.txt`（全精度 eps_star）。

## legacy 冻结

`legacy/isect.c`、`legacy/isect.h` 是 `HEAD` 原文件的逐字节拷贝，固定阈值
1e-12 的 `isect_seg/isect_polyline/isect_self` 一字未改。`build/ltable` 只链
冻结源码出交点表；新 `table legacy` 走当前库的同名 legacy 函数，两份表
`assert.sh` 逐字节 `cmp`，保证「新逻辑关闭时交点表不变」。
