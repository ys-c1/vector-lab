# isect

线段求交模块。

- `src/isect.*`：原始两段求交、折线计数、自交检测（既有 API，未改动）
- `src/sweep.*`：扫描线求交与事件排序，提供严格全序排序键

## 排序键（严格全序）

每个事件按下列元组字典序比较，任一级分出胜负即停止：

1. 事件位置 `x`
2. 事件位置 `y`
3. 事件类型 `kind`：`LEFT(0) < CROSS(1) < RIGHT(2)`
4. 斜率序：段方向规范化（起点取字典序较小端点）后按斜率升序；
   竖直段斜率为 +inf 排最后；斜率大小用方向向量叉积判定，无浮点容差
5. 段号 `seg_id`
6. 交点事件的段对 `(seg_a, seg_b)`
7. 唯一构建序号 `eid`（最终兜底，保证任意两个不同事件比较结果非零）

“键相同但段不同”的情形：同一点、同类型、同斜率的两个不同段事件
在第 4 级仍相等，由第 5 级段号分序（`bench ties` 可列出这些分组）。
重复段在输入校验阶段即拒绝，因此不会出现键完全相同的不同事件。

## 输入校验

- 零长段（两端点完全相同）：拒绝，报段号（`code=1`）
- 重复段（端点对相同，含反向）：拒绝，报两个段号（`code=2`）
- 非有限端点或空参数：拒绝（`code=3`）

## 两种排序模式

- `stable=1`：上述全序键，任意输入下顺序唯一，重跑逐字节一致
- `stable=0`：旧的不稳定键，只比较 `(x,y,kind)`，相等即返回 0；
  排序前按种子洗牌，同输入不同种子可得到不同交点次序。
  两种模式产出的交点集合相同（仅次序不同），`verify.sh` 第 7 步逐字节核对。

## 构建与验证

```
make test       # 单元测试（isect 既有测试 + sweep 全序/确定性/拒绝测试）
make bench      # 构建 bench 驱动
./verify.sh     # 七项验证：排序键、十次重跑、逐字节一致、不稳定复现、
                # 键相同段不同分组、非法输入拒绝、legacy/stable 集合一致
```

bench 子命令：`table | events | ties | rerun | canon`，输入每行
`x1 y1 x2 y2 [id]`，数据在 `data/`。
