# freq

细密纹理在空域低通下总是糊成一团：盒式/高斯核的截止宽度固定，降噪和保纹理
只能二选一。这个模块改为**频域定截止**：先看图的能量分布，再决定保留到哪。

```
去均值 → 反射填充到 2 的幂 → 二维 FFT → 按半径分环带统计平均功率
       → 以 AC 环带中位数为噪声底，选最外一个显著环带作截止
       → 1 环带宽升余弦低通 → 逆变换 → 反变换验证（预测 vs 实测保留）
```

## 跑一遍

```sh
make test     # 223 项检查：FFT、往返、选截止、两类拒绝、纯色、关新逻辑、
              # 四类纹理的模糊度对照（硬性要求：至少比同等去噪的空域低两成）
make demo     # 四类纹理 + 特殊输入的报告表，落 demo_*.pgm 图像
make bench    # 128/256/512 三档尺寸的分阶段耗时
make compat   # 空域兼容路径与 baseline/ 逐字节比对（45 个产物）
./verify.sh   # 端到端：测试、报告、耗时、拒绝、逐字节对照
```

## 四类纹理的结果

`make demo` 的实际输出（128×128，噪声幅度 24，耗时取 5 次中位数）：

| 纹理 | 截止频率 (cyc/px) | 保留能量 | 耗时 (ms) | 模糊度(频域) | 空域基线 σ | 模糊度(空域) | 降幅 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 细条纹 | 0.2539 | 99.51% | 1.83 | 0.0000 | 3.0 | 0.9969 | 100.0% |
| 棋盘 | 0.3555 | 99.63% | 1.77 | 0.0010 | 1.3 | 0.9823 | 99.9% |
| 斜纹 | 0.3555 | 99.63% | 1.80 | 0.0000 | 1.2 | 0.9705 | 100.0% |
| 点阵 | 0.5352 | 99.88% | 1.79 | 0.0007 | 0.6 | 0.2184 | 99.7% |

- **截止频率**：保留环带的右边界，单位是 cycles/pixel。条纹 0.25、棋盘/斜纹
  0.355（对角环带）、点阵 0.535，与各自的基频对得上。
- **保留能量**：截止以内 AC 总功率 / 全部 AC 总功率。频域预测值与逆变换后
  实测的 AC 方差比逐图对照，差 < 0.02（`test_retention`）。
- **模糊度**：`1 - Re<F_out, conj(F_ref)> / |F_ref|²`，以真值纹理为参照，
  只计非 DC 分量。两侧用同一把尺子 `fq_blur_degree()`，与滤波器无关。
- **空域基线**：高斯核 σ 从 0.2 扫到 3.0，只取“高频去除量不低于频域方案”
  的设置；若 σ=3.0 仍追不上频域的去噪量，就取它最强的一档。因此比较不是
  “拿不降噪的空域去比”。
- **降幅**全部 ≥ 99.7%，远超两成要求；最接近的棋盘也有 99.9%。

> 说明：模糊度以“真值纹理存在”为前提，是验证用的合成场景。真实图像没有
> 真值，`fq_blur_degree` 需两张图（滤波结果 vs 参照）才能算。

## 拒绝与纯色

| 输入 | 返回 | 截止 | 说明 |
|---|---|---:|---|
| 纯色 | `FQ_OK`，`status=FQ_ST_FLAT` | 0 | 去均值后 AC 能量为零，**单独报出**，不做滤波，输出恒等 |
| 白噪声 | `FQ_E_CUTOFF_ZERO` | 0 | 所有 AC 环带都低于显著门限，没有纹理基频 |
| 近纯色（仅 2 点微差） | `FQ_E_CUTOFF_ZERO` | 0 | 同上 |
| 角点交替（最高频） | `FQ_E_CUTOFF_HIGH` | 0.7148 | 超过奈奎斯特对角线 0.7071 |

两类拒绝的 `reason` 都会写清是哪个数字触发的（门限/底噪/峰值，或截止/上限）。
`fq_run` 被拒时输出仍是输入的副本，方便上层落盘对照。

## 怎么选截止

1. 半径按 `1/n` 分环带（共约 91 个），统计每个环带的**平均**功率。
2. 噪声底 = 全部 AC 环带平均功率的**中位数**；显著门限 = 8 × 底噪
   （另有 `1e-12 × 峰值` 的浮点下限）。
3. 显著环带中最外侧的那个，截止取到它的右边界 `(k+0.5)/n`。
4. 超过 `cutoff_max`（默认奈奎斯特对角线）拒绝；没有任何显著环带则截止为零。

倍数 8、中位数底噪这两个选择在 `test_select` 里覆盖了结构、噪声、极值三类输入；
`noise_mult` 与 `cutoff_max` 都可经 `FqOptions` 调整。

## 兼容路径：关掉新逻辑逐字节不变

原有空域滤波保留为 `fq_filter_spatial()`（可分离高斯，Q16 固定点权重，
反射边界），`FqOptions.use_freq = 0` 时 `fq_run` 完全不走频域分析。

`make compat` 在 3 种尺寸 × 3 种纹理 × 5 档 σ（含 σ=0 的空操作）上生成
45 个 PGM，与 `baseline/` 逐字节比较；当前 **0 个不一致**。`test_disable_switch`
另检查 `use_freq=0` 的输出与直接调 `fq_filter_spatial` 逐字节相同，且报告里
频域字段全为零。编译期 `-DFQ_ENABLE_FREQ=0` 时频域入口返回 `FQ_E_DISABLED`、
输出为输入副本（`verify.sh` 第 5 步）。

改动空域路径（有意）后重生成基线：`./build/compat --write`。

## 耗时

128×128 单图约 1.8–2.0 ms，其中正/逆变换各占一半左右；512×512 约 65–72 ms。
分解见 `make bench`。FFT 是基 2 迭代实现，尺寸不是 2 的幂时先反射填充。
